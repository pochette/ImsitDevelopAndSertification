## CHAT-012. Продление записью и чтением, но не просмотром состояния

| Поле | Значение |
| --- | --- |
| Требование | C-02, C-04 |
| Модуль / подмодуль | Сеансы / продление |
| Приоритет | Высокий |
| Глубина | AT |
| Предусловия и данные | Отдельный запуск с --chatbot.session-timeout=30s. Новый S; выполнять действия до истечения срока. |

| Шаг | Действие | Ожидаемый результат |
| --- | --- | --- |
| 1 | Через 2–5 секунд после создания записать сообщение; GET состояния, сохранить expiresAt E1 | 201 при записи; 200 при GET; E1 позже первоначального срока. |
| 2 | Ещё через 2–5 секунд прочитать сообщение; GET состояния, сохранить E2 | 200; E2 позже E1. |
| 3 | Сразу повторить GET состояния | 200; expiresAt по-прежнему E2. |
| 4 | Продолжать GET состояния каждые 2 секунды до момента позже E2 | До E2 — 200 без изменения E2; после E2 — 404. Просмотр не продлевает срок. |
