Не переносите результаты старой сборки в новую без повторного прогона.

- Сборка (git SHA): не заполнено
- Тестировщик (Ф. И. О.): не заполнено
- Даты начала / окончания: не заполнено
- ОС / браузер / версии JDK: не заполнено

## Итог после прогона
- Выполнено / Passed / Failed / Blocked: заполнить.
