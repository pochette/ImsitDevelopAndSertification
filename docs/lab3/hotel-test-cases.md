## HOTEL-009. Занятые номера исключаются

| Поле | Значение |
| --- | --- |
| Требование | H-01, H-02 |
| Модуль / подмодуль | Поиск / бюджет и результат |
| Приоритет | Высокий |
| Глубина | AT |
| Предусловия и данные | Проверка состояния базы выполняется существующим RoomRepositoryTest, поскольку API изменения занятости отсутствует. Запуск: .\mvnw.cmd -pl hotel -Dtest=RoomRepositoryTest test. Сверить фактические утверждения теста; для ручного прогона нужен отдельный тестовый экземпляр базы. |

| Шаг | Действие | Ожидаемый результат |
| --- | --- | --- |
| 1 | Запустить существующий тест excludesOccupiedRooms: отметить один номер занятым и выполнить поиск с money=600 | В результате 24 номера; изменённый номер отсутствует. |
| 2 | Запустить returnsEmptyWhenAllAffordableRoomsOccupied: отметить все ECONOMY занятыми, выполнить поиск с money=200 и money=600 | Репозиторий возвращает пустой список при 200 и 15 номеров при 600; после каждого теста транзакция откатывается. Это проверка репозитория, а не HTTP-ответа. |
