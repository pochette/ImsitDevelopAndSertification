# Test Cases — Swagger UI и General

Все кейсы первоначально имеют статус **Не выполнен**. Результаты заносятся в [журнал](execution-log.md).

## SW-001. Отображение документации

| Поле | Значение |
| --- | --- |
| Требование | UI-01, G-01 |
| Модуль / подмодуль | Swagger / GUI и General |
| Приоритет | Средний |
| Глубина | AT |
| Предусловия и данные | Выполнить отдельно для Chatbot (8080) и Hotel (8081) в выбранном браузере. Приложения запущены, у Hotel исходные данные. |

| Шаг | Действие | Ожидаемый результат |
| --- | --- | --- |
| 1 | Открыть /swagger-ui.html | Отображается Swagger UI и название нужного API, без Fetch error. |
| 2 | Раскрыть операции | Chatbot: 5 операций; Hotel: 1 GET /bookings. Отображаются параметры, тела и описания статусов. |
| 3 | Открыть /v3/api-docs | 200; JSON OpenAPI с title и paths соответствующего приложения. |
